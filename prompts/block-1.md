# Block 1 prompts: First contact

## S1: Setup check

> Reply with the word ready.

## P1.1: The vague agenda (practice, activity 1b)

Everyone runs this exactly as written, in a new chat.

> Write an agenda for our team meeting next week, with action items.

**Look for:** topics, times, names, and action items that you never gave it.

## T1.1: "What do you know?" (behaviour test, instructor demo in the talk)

Run live in a new chat during talking point 2.

> What's on the agenda for my team's meeting next week?

**What it tests:** whether ChatGPT admits it has no information, or invents an
answer. Either result teaches the point: it only knows what's in the
conversation. If it asks for details, show the room that this is the behaviour
you *want*, and that you'll ask for it on purpose in Block 4.

## T1.2: Run it twice (behaviour test, fast finishers in 1b)

Run P1.1 again in a **second new chat**. Compare it with your first result.

**What it tests:** variation. Same prompt, same person, different answer.

## T1.3: Ask about its limits (behaviour test, optional)

> What is your knowledge cut-off date, and what kinds of questions should I not
> rely on you to answer accurately?

**What it tests:** its account of itself. The answer is often reasonable, but it
is still generated text, not a specification. Ask the room: *how would you check
whether that's true?*
