# Activity 4b: Reverse-Engineer the Prompt

Block 4 · Outcomes: LO2, LO3 · Time: 20 min · Format: teams

## For the instructor

**Why this game:** working backwards from an output to its prompt teaches which
features of a prompt produce which features of an output. It's also a puzzle,
which analysts tend to enjoy.

**Prep (the day before):** run each hidden prompt below in a **new chat** in the
learners' version of ChatGPT. Save the outputs. Learners see only the outputs.

**Timing**

| Min | Step |
| --- | --- |
| 0–2 | Rules: here's what ChatGPT produced. Write the prompt that made it. Run your guess and compare |
| 2–16 | Teams work through all three, about four minutes each |
| 16–20 | Reveal each hidden prompt. Score each team's guess on the feature checklist |

**Scoring:** for each output, one point per feature from the checklist that the
team's prompt asked for.

### Hidden prompt 1

> Turn these notes into a table with three columns: Action, Owner, Due date. Use
> only the notes. If an owner or date is missing, write [CHECK].
>
> Notes: Park to send revised survey to OMB liaison by Oct 30. Ruiz to confirm
> dashboard go-live. Someone needs to update the FAQ. Okafor and Lin to circulate
> charter draft by Nov 4.

**Features:** a three-column table · these exact column names · [CHECK] for
missing owner and date · no invented owners · four rows.

### Hidden prompt 2

> Rewrite this email for a senior executive. Start with a one-sentence bottom
> line. Under 80 words. No acronyms.
>
> Email: Per the FY27 DC guidance from OMB and our convo w/ OCFO, we're tracking
> to submit the PB inputs NLT 11/20 contingent on SME review of the PMA crosswalk,
> which is currently at ~60% but we have some risk on the IT side re: the API.

**Features:** BLUF first sentence · under 80 words · no acronyms · executive tone
· mentions the risk.

### Hidden prompt 3 (the twist)

> I need an agenda for a meeting next week. Before you write anything, ask me
> three questions you'd need answered to make it useful.

**Features:** output is **questions, not an agenda** · exactly three · they're
about the meeting's purpose, attendees, or length.

Teams rarely guess that prompt 3 asked for questions. That's the reveal to
enjoy, and it sets up refinement move 3.
