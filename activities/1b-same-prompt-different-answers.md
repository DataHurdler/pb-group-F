# Activity 1b: Same prompt, different answers

Block 1 · Outcome: LO1 · Time: 12 min · Format: individual, then tables

## For the instructor

**Why this activity:** learners see for themselves that outputs vary and that
missing facts get invented. The talk that follows just names what they saw.

**Setup:** the prompt on screen, large enough to copy exactly.

**Timing**

| Min | Step |
| --- | --- |
| 0–1 | "New chat. Type it exactly. Don't improve it." |
| 1–5 | Run it |
| 5–12 | Tables compare and answer the two questions |

**What good looks like:** tables notice that every agenda has specific topics,
times, and sometimes names or dates, that these differ between people, and that
none of them were in the prompt.

**If a table finishes early:** run it again in a new chat. Is it different from
your own first answer?

---

## For learners

Start a **new chat** and send this prompt exactly as written:

> Write an agenda for our team meeting next week, with action items.

**At your table:**

1. Put your agendas side by side. List two ways they differ.
2. Find three specific details (topics, times, names, action items). Where did
   each one come from?

**Time:** 12 minutes
