# Activity 1.1: Same prompt, different answers

Session: 01 · Outcome: LO1 · Time: 10 min · Format: individual, then tables

## For the instructor

**Why this activity:** learners see two things for themselves before you explain
them: outputs vary, and missing facts get invented. The lecture that follows
just names what they saw.

**Setup:** the prompt on a slide, large enough to copy exactly.

**Timing**

| Min | Step |
| --- | --- |
| 0–1 | Brief: type it exactly as written, in a new conversation |
| 1–4 | Run it |
| 4–10 | At tables: compare. Fill in the two questions |

**What good looks like:** tables notice that every version has specific details
(start dates, number of days, eligibility rules, contact names) that differ
between learners, and that none of those details were in the prompt.

**Likely mistakes:** someone "improves" the prompt before running it. Ask them to
run the exact text too; the comparison only works if everyone sends the same
thing.

**If a table finishes early:** run it a second time in the same tool. Is it
different from your own first answer?

---

## For learners

**Your task:** start a new conversation and send this prompt, exactly as written:

> Write a short announcement to staff about the new telework policy.

**Then, at your table:**

1. How different are your announcements? List two differences.
2. Find three specific details (dates, numbers, rules, names) in your
   announcement. Where did each one come from?

**Time:** 10 minutes
