# Pre/post check

Status: draft. Five questions, about five minutes. Taken at 9:23 and again at
15:25, with **the same questions both times**.

It's anonymous and not graded. Say so, and say that "I don't know" is a good
answer in the morning.

To compare the two attempts anonymously, ask learners to write the same made-up
code word on both (a pet's name works).

---

## Questions

**1. You run the exact same prompt twice and get two noticeably different
answers. Why?** (LO1)

- A. The tool is malfunctioning
- B. It generates text by predicting likely words, with some built-in variation
- C. It learned from your first prompt and changed its answer on purpose
- D. I don't know

**2. A colleague asks an AI tool what a specific federal regulation requires. The
answer is detailed, confident, and includes a section number. What's the best
next step?** (LO1, LO4)

- A. Use it; the section number shows it's accurate
- B. Ask the tool "Are you sure?"
- C. Look up the section in the official source (for example, eCFR) and read it
- D. I don't know

**3. Which of these is generally safe to paste into an AI tool that is NOT
approved for sensitive information?** (LO4)

- A. A draft letter that includes an employee's name and medical leave details
- B. A press release already published on your agency's public website
- C. Pre-decisional budget figures from a staff meeting
- D. I don't know

**4. You asked for a summary for frontline staff. It's accurate but too long and
too formal. What's the best next move?** (LO3)

- A. Re-run the same prompt and hope for a better version
- B. Follow up: "Cut this to 150 words, in plain language, for frontline staff"
- C. Switch to a different AI tool
- D. I don't know

**5. Which prompt is most likely to produce a usable first draft?** (LO2)

- A. "Write a reply to this email."
- B. "You are a world-class communications expert. Write an excellent reply."
- C. "Draft a reply to the email below from a grant applicant. Our processing time
  is 10–12 weeks. Keep it under 120 words, plain and friendly. Don't promise a
  decision date. [email pasted]"
- D. I don't know

---

## Answers

| Q | Answer | What a wrong answer suggests |
| --- | --- | --- |
| 1 | B | C: thinks the tool learns permanently from each user. Address in Session 01, idea 1 |
| 2 | C | A or B: trusts fluency or self-checking. This is the core of Session 01, idea 2 |
| 3 | B | A or C: doesn't yet see personnel or pre-decisional information as sensitive. Scenario B targets this |
| 4 | B | A: hasn't learned to point at the problem. Session 03, move 1 |
| 5 | C | B: believes in role-prompt folklore over context. Session 02 hook |

## Using the results

- **Morning:** if most of the room gets a question right, go lighter on that
  topic. If most get Q3 wrong, spend extra time on the safe-use card.
- **Afternoon:** tell the room how the scores moved.
- **Afterwards:** a question nobody improved on points at the session to fix.
