# Prompt checklist

One page. Keep it next to your keyboard.

## The five parts

| Part | Ask yourself | Example |
| --- | --- | --- |
| **Task** | What exactly do I want produced? | "Draft a reply to this email…" |
| **Context** | What facts does it need that it can't know? Paste the source | "Processing time is 10–12 weeks. [pasted email]" |
| **Audience** | Who reads this, and what do they care about? | "A frustrated small-business owner, new to federal grants" |
| **Format** | What length, structure, and tone? | "Under 120 words, plain language, warm but professional" |
| **Guardrails** | What must it not do? What should it do when unsure? | "Use only these facts. Don't promise dates. Write [CHECK] if something's missing" |

## When the first answer isn't right

1. **Point at the problem.** "Paragraph two dropped the deadline. Restore it
   exactly." Don't just re-run.
2. **Show an example** of the style or format you want.
3. **Ask it to ask you** up to five questions before drafting.
4. **Break it into steps:** list the requirements, then draft, then confirm each
   one is there.
5. **Ask what it changed**, then check that list yourself.

Start a **new conversation** when it keeps repeating a mistake or you switch
tasks.

## Before you use the output

- [ ] Every name, number, date, and deadline matches the source
- [ ] Every citation (CFR, USC, policy) has been looked up in the primary source
- [ ] Nothing was added that the source doesn't support: penalties, promises,
      statistics
- [ ] "May" hasn't become "will", and conditions haven't disappeared
- [ ] It reads right for the audience: tone, plain language, accessibility
- [ ] You'd be comfortable signing it, because you are

## Before you paste anything

See the safe-use card. If in doubt, leave it out.
